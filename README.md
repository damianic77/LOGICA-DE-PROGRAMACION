## 📋 Descripción del Proyecto

Este proyecto consiste en un juego interactivo de consola desarrollado en Python. Permite a un usuario competir contra la computadora seleccionando una de las tres opciones tradicionales (*piedra*, *papel* o *tijera*), evaluando las reglas del juego y controlando la ejecución continua hasta que el usuario decida salir.
